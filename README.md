# Spinor-Helicity Amplitude Simplification via Self-Supervised Oracle Trajectories

Code and data for reproducing the spinor-helicity amplitude simplification results from:

**"Learning to Unscramble: Simplifying Symbolic Expressions via Self-Supervised Oracle Trajectories"**
David Shih
[arXiv:2603.11164](https://arxiv.org/abs/2603.11164)

## Overview

This repository implements a self-supervised learning approach for simplifying spinor-helicity amplitude expressions. The method formulates simplification as a Markov decision process (MDP), where oracle trajectories are generated by scrambling simple expressions and reversing the operations. A transformer-based policy network is trained on these trajectories to predict, at each step, which spinor-helicity identity (Schouten, momentum conservation, or momentum-squared) to apply and to which bracket.

Three separate pipelines are provided for 4-point, 5-point, and 6-point amplitudes.

**Key results** (target-relative solve rate):
- 4-point: 99.9%
- 5-point: 99.6%
- 6-point: 99.4%
- Yang-Mills 5-point gluon amplitudes (8--228 terms): 100% simplified to Parke-Taylor

## Full Reproduction

### 1. Generate Training Data

Training data consists of oracle trajectories: scrambled spinor-helicity expressions paired with the sequence of identity applications that simplify them.

```bash
# Generate 5-point oracle data (parallelizable)
python src/generate_oracle_worker_5pt.py \
    --worker_id 0 --num_samples 1000 --n_point 5 \
    --output_dir data/oracle_5pt_chunks/

# Similarly for 4-point and 6-point
python src/generate_oracle_worker_4pt.py \
    --worker_id 0 --num_samples 1000 --n_point 4 \
    --output_dir data/oracle_4pt_chunks/

python src/generate_oracle_worker_6pt.py \
    --worker_id 0 --num_samples 1000 --n_point 6 \
    --output_dir data/oracle_6pt_chunks/
```

For large-scale generation, use the Condor submit files in `condor/` (e.g., `condor/generate_oracle_5pt.sub`) with the worker shell scripts in `scripts/`.

### 2. Convert to Training Transitions

```bash
# Convert oracle trajectories to (state, action) transitions
python src/convert_oracle_5pt_to_multilabel_worker.py \
    --input_dir data/oracle_5pt_500k \
    --output_dir data/transitions_5pt_chunks \
    --worker_id 0 --num_workers 1 \
    --n_point 5 --max_terms_obs 25 --max_terms_action 25 \
    --max_brackets_per_term 15 --max_brackets 20
```

### 3. Train Model

```bash
python src/train_sft_5pt.py \
    --transitions_dir data/transitions_5pt_merged \
    --output_dir models/my_5pt_model \
    --epochs 200 --batch_size 256 --lr 1e-4
```

### 4. Evaluate Model

```bash
python src/eval_sft_5pt.py \
    --checkpoint models/my_5pt_model/best_model.pt \
    --test_data data/paper_test_5pt.pkl
```

### 5. Generate Paper Figures

```bash
# Main amplitude figures (requires results/ data)
python scripts/amp_paper_figures.py

# YM 5-point solve rate plot
python scripts/plot_ym5pt_solve_rate.py
```

## CDS Baseline Comparison

Pre-computed evaluation results from the CDS baseline (Dersy, Schwartz, Zhang, [arXiv:2206.04115](https://arxiv.org/abs/2206.04115)) are included in `results/paper_model_eval/`. These are used by the paper plotting script for comparison.

To run the CDS baseline yourself, use:
```bash
python src/eval_paper_model_5pt.py
```
This requires the pre-trained CDS models from the `spinorhelicity` submodule.

## Condor Job Submission

Example HTCondor submit files are in `condor/`. Before use, update the placeholder paths (`/path/to/...`) to match your local installation.

## Training Data

Training data (~2GB per n-point) is not included in this repository due to size. Generate it using the oracle workers above. The pre-trained model checkpoints and test data are included.

    generate_oracle_worker_{4,5,6}pt.py    # Oracle data generation workers
    convert_oracle_{4,5,6}pt_to_multilabel_worker.py  # Transition conversion
    eval_paper_model_{4,5,6}pt.py          # CDS baseline evaluation
    spinhelicity_env.py                    # Spinor-helicity environment utilities
    beam_search_5pt.py                     # Beam search for 5-point expressions
    eval_large_expr_orchestrator.py        # Orchestrator for large expression eval
